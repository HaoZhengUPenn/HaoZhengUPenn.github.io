# 郑豪 · 交互式学术履历与「人生 K 线」/ Hao Zheng · Interactive CV & Life Candlestick

把一份 21 页的中文 CV（PDF）转成一个可交互的单页网站：按类型分标签阅读，
再用「年份时间轴 + K 线 + 动画」把 2009–2031 的学术轨迹讲成一个故事。
**中英双语，一键切换**（内容取自同名的中文版与英文版 CV）。

## 打开方式

- 双击 **`郑豪-简历-交互版.html`** —— 单文件版，CSS/JS 全部内联，可直接分享或用浏览器打开，无需联网。
- 或打开 **`index.html`** —— 分文件版（`assets/` 目录需同目录），便于修改维护。
- 均为纯静态页面，`file://` 直接打开即可，无需服务器。
- **默认英文**；右上角 **中 / EN** 一键切换中文（记忆到 localStorage），切换时保留当前标签页与动画节点。

## 交互细节

- **上一个 / 下一个**：手动步进；**自动播放**：按每个节点的建议间隔（2.2–3.6 s）自动推进，右上角进度条显示当前节点剩余时间。
- **自动聚焦**：默认开启，视口自动取当前年份 ±4 年的窗口并平滑过渡；点「聚焦：自动」可切换为「全景」查看 2009–2031 全貌。
- **重绘 K 线**：重新播放「逐根生长」的绘制动画。
- 悬停 K 线显示该年的开/高/低/收、涨跌幅与当年产出；点击蜡烛跳到该年节点。
- 右上角可切换 **暗色 / 亮色** 主题（记忆到 localStorage）。
- 移动端自适应（时间轴横向滚动、面板单列堆叠）。

## 可分享的 URL 参数

- `index.html?step=12#journey` —— 直接定位到第 12 个节点（1 起算的下标从 0 开始，`step` 为 0–23）。
- `&lang=en` —— 以英文打开（**默认**）；`&lang=zh` 为中文。
- `&theme=light` —— 亮色主题。
- `&static=1` —— 关闭所有动画（适合截图或 `prefers-reduced-motion`）。

## 「人生指数」是怎么算的

> 指数 = 成长基准（年化 13.5%）× 当年度产出强度

年度活动分：

```
S(y) = 3·SCI + 1.6·EI + 1·会议 + 2·专利 + 0.5·讲座
     + 4·新任职 + 3·获奖 + 2·新立项 + 1.2·√(经费万元)
A(y) = S(y) / max S            （2026 年为部分年度，按 12/10 折算）
L(y) = 210 + 620·A(y) + 30·(y − 2011)
```

- 蜡烛：开盘 = L(y−1)，收盘 = L(y)，**上下影线由该类事件在年内的月份分布决定**（4 月答辩的项目会出现在年中）。
- 预测段：以 2024–2026 复合增速为基准并逐年收敛，2027 年叠加 ECS 立项加成，扇形区随年份线性放开。
- 说明：该指数是**可视化建模**，不是真实财务或评价数据；预测仅为叙事展示，见页面页脚声明。

## 数据来源与录入

全部内容取自 `郑豪简历.pdf`（21 页，2026 年 11 月版），逐条录入为结构化数据：

- `assets/data.js`：中文档案（个人信息、教育、任职、项目、专利、获奖、教学、学术服务、24 个叙事节点）。
- `assets/data2.js`：**84 篇论文**与 **122 场受邀讲座**（论文/讲座题目本身为英文）。
- `assets/data-en.js`：英文档案，对应 `CV_Hao.pdf`（英文版，21 页）；论文与讲座复用中文数据，仅映射作者角色与收录标签（`第一作者 → First author`、`中科院一区 → CAS Q1`、`SSCI中科院一区 → SSCI · CAS Q1`）。
- `assets/model.js`：年度聚合 + 指数 / OHLC / 预测模型（接受任意一份数据集）。
- `assets/kline.js`：Canvas K 线引擎（HiDPI、视口动画、逐根绘制、预测扇形、MA、成交量）。
- `assets/app.js`：双语字典、标签页渲染与动画播放引擎。

简历口径（约 80 篇论文、120 余场讲座）与实际条目数差异，页面中已注明。
英文版中的金额沿用英文 CV 的 `HKD / CNY + USD` 双币写法。

## 自测

```bash
node tools/bundle.mjs        # 重新打包单文件版
node tools/verify-journey.mjs "<chrome 路径>" "file:///.../index.html#journey" out.png
```

`verify-journey.mjs` 通过 CDP 驱动无头 Chrome，验证 18 项交互：节点步进、自动播放推进/暂停、
键盘切换、时间轴跳转、K 线悬停提示、标签页切换与筛选、论文搜索等（当前 18/18 通过）。
